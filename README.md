# MrarusDots
My (mainly stolen) Arch Linux config files (optimized for a Thinkpad T480)

# Software
* Window Manager: `swaywm'
* Terminal: `foot`
* Launcher: `tofi`
* Status Bar: `waybar`
* Screenshot Tool: `grim`

# Installation:

* git clone the repo
* copy the files into .config
* make sure to edit sway's `config` file according to your machine and your likings; make sure to set the right inputs and outputs with
  `swaymsg -t get_inputs`
 and 
  `swaymsg -t get_outputs`. 
* reload sway

# Dependencies

* [arch wiki, aka RTFM](https://wiki.archlinux.org/title/Sway)
* [sway git](https://github.com/swaywm/sway/wiki)
